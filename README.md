
# Smart Cow Udder Detection

Sistem cerdas untuk membantu mendeteksi indikasi abnormalitas pada ambing sapi perah menggunakan sensor suhu dan teknologi computer vision berbasis YOLOv8n.

## Features
- Pengukuran suhu menggunakan sensor MLX90614.
- Pengambilan gambar menggunakan ESP32-CAM.
- Deteksi kondisi ambing menggunakan YOLOv8n.
- Pemrosesan model pada Raspberry Pi 4 Model B.
- Tampilan hasil melalui OLED.
- Notifikasi hasil melalui Telegram.

## Hardware
- Raspberry Pi 4 Model B
- ESP32-CAM
- MLX90614
- OLED SSD1306

## Software
- Python
- TensorFlow Lite
- YOLOv8
- OpenCV
- Arduino IDE
